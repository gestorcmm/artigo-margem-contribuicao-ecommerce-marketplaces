# Artigo Margem de Contribuição

Arquivos nesta pasta:

- `artigo-margem-contribuicao.html` - artigo completo.
- `Artigo-MC-slides.html` - deck de slides com navegação e link para o artigo.
- `Artigo-MC-slides.pdf` - exportação em PDF do deck.
- `layouts-exemplos.html` - visualizações de layout alternativas.
- `modular/index.html` - versão modular do artigo.
- `slides/` - slides individuais do artigo em HTML.
- `modular/simulador.html` - simulador de margem de contribuição.
- `Artigo-MC-completo.zip` - pacote contendo todos os arquivos.

## Slides individuais

Abra `slides/index.html` para acessar a sequência de slides do artigo. Cada slide está separado em sua própria página HTML e navega com botões "Anterior" e "Próximo".

## Como usar

1. Abra `Artigo-MC-slides.html` no navegador.
2. Clique em **Abrir artigo completo** para abrir `artigo-margem-contribuicao.html` em nova aba.
3. Se precisar do artigo independente, abra diretamente `artigo-margem-contribuicao.html`.
4. Para tests locais, use o pacote `Artigo-MC-completo.zip` se preferir mover os arquivos juntos.
